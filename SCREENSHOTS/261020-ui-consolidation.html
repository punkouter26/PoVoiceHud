  1. More room for the headline (U6, U10). The tally and ✕ are gone from the pill; the headline gains about 120 px. It is now a real button, so Tab and Narrator reach the panel too. Right-click the pill for the panel, Recap, Settings and Close PoVoiceHud.
  2. Tally as a bar (U6). The pill's bottom edge shows this session's verdicts as shares of green, red and amber. Hovering the headline gives the numbers, and so does the Session tab.
  3. Quieter card (U4). Copy and put-away appear only while the pointer or keyboard focus is on the card. They stay in the tab order, and right-click (or press and hold) offers Right / Wrong / Copy / Put away. Narrator reads each new answer as it arrives (U10).
  4. Shelf rows (U5). The bracket tags ([SCHEMA], [DOCS]) become icons. A fact check shows its verdict instead. Each row now shows how long ago it was said, and the shelf holds three rows instead of six.
  5. +N more in Session (U5). Says how many older cards the Session tab holds, and opens it.
  6. One switch (U8). Cards | Session replaces the transcript button and ✦, so only one view is ever open.

  1. Constellation strip. It is 76 px instead of 190, with the stars spread over less margin. Hover still names a star and a click brings its card back. The axis caption moved into the tooltip, so it no longer covers the first stars.
  2. Tally. Split by you and the call, plus your ratings for the last 7 days. Before, this was only in a tooltip.
  3. Timeline. Every line heard (up to 40 entries, lines and cards together), with the speaker in colour…
  4. …and the cards it brought underneath. Click one to make it the focus card again. Any card of the session can now come back, not only the six on the shelf. A recap opens this tab. A new card that opens the panel shows Cards.

  1. Model and API key share a row. In the demo the model isn't set up yet, so its fields are open. Once it works, it folds to one line with a status dot.
  2. Repository folded (U2). It shows org/project/repo, the folder's name, or None — fact-checking only, with Change…/Add…. An Azure DevOps URL without a token stays open, and so does one with an error. The dot is grey before a check, then green or red.
  3. One Check connections (U1). It replaces Test and Test repository, checking the model and the repository (when there is one) in parallel. Each result shows under its own line.
  4. 2×2 switches (U3). Wikipedia, Start with Windows and Sounds. Their explanations moved to tooltips, and the Wikipedia privacy note is also the switch's help text for Narrator.
  5. Effects as a three-part switch (U3). Off | Subtle | Full replaces the drop-down. Pressing the level that is already on leaves it on.
  6. Close PoVoiceHud lives here now that the pill has no ✕ (U6).
